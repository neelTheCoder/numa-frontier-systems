# NUMA · Frontier Systems

A minimalist website for **non-invasive semantic neural decoding**: upload a single-instance
`.bdf` EEG recording and the NUMA v6 model guesses which of 36 imagined animals/tools it is,
then pops up the matching picture. Includes the project's mission, v6 cross-validation results,
and a walkthrough of how the decoder works.

This repo is a **pure static site** (no build step) — Vercel serves it as-is. The heavy
model inference runs on a **separate API** (`predict_numa.py`), because PyTorch + MNE are far
too large to run inside a Vercel serverless function.

```
.
├── index.html        # the site
├── styles.css        # styling (minimalist, dark)
├── app.js            # upload → API → image popup
├── manifest.json     # class → picture mapping (auto-generated from /pictures)
├── vercel.json       # static config
├── pictures/         # animals/ + tools/ images shown on prediction
└── plots/            # v6 result figures
```

## 1. Deploy the frontend (Vercel)

1. Push this folder to GitHub (already wired to `numa-frontier-systems`).
2. In Vercel → **New Project** → import the repo. Framework preset: **Other** (no build command,
   output directory = root). Deploy.

That's it — Vercel hosts the static files directly.

## 2. Deploy the prediction API (separate host)

The browser uploads the `.bdf` straight to your API, so it never hits Vercel's 4.5 MB body limit.
Host `predict_numa.py` (in the `numa_model` repo) on any platform that fits `torch` + `mne`:

- **Hugging Face Spaces** (easiest free option), **Render**, **Railway**, or **Fly.io**.
- Put a v6 checkpoint (`enigma_v6_final.pt` or `enigma_v6_fold2.pt`) next to it.
- Start command:
  ```
  gunicorn predict_numa:app -b 0.0.0.0:$PORT -w 1 -t 300
  ```
- CORS is already enabled in `predict_numa.py`, so the Vercel page can call it cross-origin.

## 3. Point the site at the API

Tell the frontend where the API lives, either:

- **Permanent:** edit `index.html` →
  `<meta name="numa-api-base" content="https://your-api-host">`, or
- **Quick test:** open the site with `?api=https://your-api-host` appended to the URL
  (saved to `localStorage` for next time).

Until an API URL is set, the page loads fully and shows a small "no server configured" notice
on the upload card.

## Notes

- `manifest.json` is regenerated by scanning `pictures/animals` and `pictures/tools`; class names
  match the model's labels exactly.
- **Research demonstration.** v6 is reliably above chance (≈3.6% balanced accuracy vs 2.8% chance,
  on a balanced 36-class problem) but absolute accuracy is modest by design of the problem.
